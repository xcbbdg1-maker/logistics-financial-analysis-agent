# 智慧物流财务分析 Agent

面向智慧物流业务场景的财务与运营分析助手，重点覆盖收入、成本、毛利、营业利润、现金流、时效、签收率、装载率、异常赔付、仓配效率和客户集中度等关键指标。

## 项目定位

该项目用于支持物流企业在以下场景中进行快速诊断与复盘：

- 分析收入构成与盈利质量
- 判断单票/单件成本与毛利率变化趋势
- 评估分拨、仓配、干线、末端派送各环节的经营效率
- 识别异常成本、赔付、时效和退货问题
- 对接管理层汇报所需的 KPI 概览和行动建议

## 主要能力

- 物流价值链财务拆解
- 关键业务 KPI 监控
- 成本与毛利率分析
- 运营效率与服务质量评估
- 经营异常识别与改进建议
- 管理报告和复盘支持

## 适用场景

- 物流公司经营分析
- 仓配网络效率评估
- 业务数据看板支持
- 财务分析与运营复盘
- 业务拓展策略评估

## 示例分析维度

- 营业收入：运费收入、增值服务收入、仓储收入
- 成本结构：人力、燃油、仓储、设备、外包、异常赔付
- 经营效率：装载率、时效达成率、签收率、转运率
- 财务质量：毛利率、净利率、现金流转换、回款情况
- 运营风险：重复投诉、派送延误、仓配损耗、分拣差错

## 核心原则

- 以业务事实为基础，避免纯财务数字脱离运行逻辑
- 关注价值链各环节的成本与收益动因
- 将 KPI 与财务结果相互校验，提升分析可信度
- 输出结构化建议，便于管理层决策与执行
